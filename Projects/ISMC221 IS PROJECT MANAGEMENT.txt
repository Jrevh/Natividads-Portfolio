Project Objectives
This project management plan is designed to develop a digital event management system with
the primary goal of providing the following functions:
● Develop a centralized system for managing client bookings and event execution.
● Implement a real-time inventory tracking system for reusable decorations and
supplies.
● Improve staff scheduling and assignment through an automated workforce
management tool.
● Enhance financial tracking with a digital invoicing and payment management
system.
● Integrate digital tools for vendor coordination and logistics planning.
● Ensure the system is mobile-friendly and accessible offline for on-site event
management.
Scope
This project includes the development of features essential to digital event
management. The key components of the Happy Pixies Digital Event Management
System are client booking and event execution management, along with finance and
accounting functionalities such as payments, invoicing, and budgeting. The system will
also support staff scheduling and workforce management, as well as inventory and
warehouse tracking to manage reusable supplies. Procurement and supplier
coordination, logistics and event-day management, and customer relationship
management (CRM) will be integral parts of the platform. Additionally, the plan includes
elements of digital transformation, including the integration of tools like Google
Workspace and support for online inquiries and contract management.
The project will not include e-commerce functionalities beyond those related to
event bookings. It will also exclude the development of a full-scale enterprise resource
planning (ERP) system, as well as the implementation of advanced AI-based automated
decision-making for event planning.

Quality Management
To ensure the highest level of quality throughout the development of the Event Management
System, the following processes will be implemented:
● Quality Standards
○ Adherence to ISO/IEC 25010 Software Quality Standards
○ User satisfaction, system reliability, and mobile responsiveness are key quality
indicators
● Quality Assurance Activities
○ Regular code reviews using GitHub
○ Design reviews with UX/UI mockups
○ Weekly testing sessions led by the QA Tester
○ Requirement traceability matrix to ensure all deliverables are met
● Quality Control Procedures
○ Automated testing scripts for form validations and data processing
○ Manual testing for usability and UI responsiveness
○ UAT (User Acceptance Testing) in October 2025
● Documentation
○ Test cases, bug reports, QA logs maintained using Google Sheets

Closure

● Final Deliverables
○ Fully functional EMS (web and mobile)
○ Documentation (user manual, developer guide)
○ Final QA reports and testing results
